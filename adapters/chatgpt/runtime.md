installed native agents. Use the Team Leader instructions and consult the role
reference for bounded sequential role passes. Label these passes as sequential,
and never present them as independent review or actual delegated agents.

current tools and permissions before using them; pass each specialist definition
and task contract explicitly. The local Codex TOML custom-profile mechanism is
documented separately and must not be assumed for ordinary ChatGPT Projects.
