# Manual ChatGPT import

1. Create or open a ChatGPT Project.
2. Copy `project-instructions.md` into its project instructions. If the client
   rejects its length, upload that file and use the short instruction:
   "Act as Development Agent Team's Team Leader. Read the uploaded
   project-instructions.md and specialist-reference.md before engineering work."
3. Upload `specialist-reference.md` and relevant non-sensitive project context.
   A ChatGPT Project does not automatically grant access to local folders.
4. Ask the leader to handle a concrete task. Check whether the current environment
   provides real delegation and file/command tools. Use labelled sequential passes
   otherwise; do not claim independent code review from role switching.
5. In ChatGPT Work, explicitly request subagents where available. Pass their
   definitions and boundaries in each assignment. Account availability and host
   policy decide whether delegation is possible.

A Custom GPT can likewise use these files as instructions/knowledge, subject to
the client's current limits. This export does not create or publish a GPT, connect
tools, modify account settings, or provide an automatic global installation.
Never upload private local context or credentials. Update uploads manually when
the framework or relevant shared project context changes.
