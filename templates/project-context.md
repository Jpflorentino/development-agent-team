# Shareable project context

Technical context template for `.ai-team/context.md`. Review before sharing; versioning is opt-in. No secrets, unnecessary personal data, full conversations, copied source or per-task plans. The Team Leader is the single consolidating writer. Use compact dated entries such as `- [YYYY-MM-DD VERIFIED] Fact; source: path or approved decision.` Preserve decisions and revalidate stale facts against code and tools. Suggested starting budget: 1,500–3,000 tokens, adjusted to the project.
