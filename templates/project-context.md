# Project — agent context

Shared project brain template for `agents/<project>-context.md`. Consumer copies remain private and excluded from Git publication. No secrets, unnecessary personal data, full conversations or copied source. The Team Leader is the single consolidating writer. Specialists also read and maintain their assigned `agents/contexts/<role>-context.md`; read-only reviewers propose notes for the leader to save. Use compact dated entries such as `- [YYYY-MM-DD VERIFIED] Fact; source: path or approved decision.` Preserve decisions and revalidate stale facts against code and tools. Preserve comprehensive project knowledge without an arbitrary small token cap. Update after decisions, accepted work, tests, blockers and phase transitions, and before handoff/session end. Include last-update time, an index of technical contexts and safe recovery state. On first use in an existing application, build actual context before application changes. Read shared facts and your own role's context first; inspect task-specific sources when necessary.
